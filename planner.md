# Planner: Session Report Email Share (Windows Compatibility & Multi-Provider Solution)

## 1. Problem Statement
In the **Session Report Builder** (`src/components/SessionAnnouncementGenerator.jsx`), the Quick Share shortcut for **Email** functions as expected on macOS (opens Apple Mail with subject and body pre-filled), but **fails to open or does nothing on Windows machines**.

---

## 2. Root Cause Analysis

### Why it works on macOS
1. **Default Protocol Handler**: macOS ships with **Apple Mail** pre-installed and globally registered as the default handler for the `mailto:` URI scheme out-of-the-box.
2. **Buffer Capacity**: macOS system URL handlers accept large URI buffers without strict low-level shell character truncation.

### Why it fails on Windows
1. **Missing Default Email Application (Root Cause A)**:
   - Modern Windows 10 and Windows 11 systems **do not come with a configured desktop mail client** out-of-the-box unless Microsoft Outlook (desktop) is installed and set up.
   - Microsoft has deprecated the old UWP Mail & Calendar app in Windows 11.
   - Most Windows tutors and teachers rely exclusively on **webmail** (Gmail inside Google Chrome or Microsoft Edge).
   - Because web browsers on Windows do not automatically bind the operating system's `mailto:` protocol without explicit user configuration, clicking a plain `<a href="mailto:...">` results in:
     - **Silent failure** (browser triggers nothing because no OS handler responds), OR
     - A confusing system prompt asking the user to choose an app from the Microsoft Store.
2. **Windows Shell 2,048-Character URL Limit (Root Cause B)**:
   - Windows executes protocol associations via the Win32 `ShellExecute` / command-line API, which enforces a strict limit of **2,048 characters**.
   - Session reports generated by `SessionAnnouncementGenerator` contain extensive structured text:
     - Header, session number, PST date, IST date
     - Parent greeting
     - Topics covered (often multi-line)
     - Homework assigned
     - Homework status/score
     - Teacher remarks and feedback
     - Signature and Google Classroom reminders
   - When encoded via `encodeURIComponent()`, every space becomes `%20` (3 characters) and newlines become `%0A` (3 characters).
   - A standard report easily reaches **2,500 to 4,500+ encoded characters**.
   - When a `mailto:` link exceeds ~2,000 characters, Chrome and Edge on Windows **silently discard the navigation**, leading to zero reaction on click.

---

## 3. The Technical Solution

Instead of relying solely on a fragile, desktop-only `mailto:` link, implement a **Smart Multi-Provider Email Dispatcher** with built-in Windows fallback and length protection.

### Share Options Provided to the User:
1. ✉️ **Gmail (Web) [Recommended for Windows]**:
   - Opens `https://mail.google.com/mail/?view=cm&fs=1&su=${subject}&body=${body}` in a new tab.
   - Completely bypasses Windows OS protocol association issues.
   - Works 100% reliably in Chrome, Edge, Brave, and Firefox on Windows, Mac, Linux, and Chromebooks.
   - Directly matches the Google Classroom ecosystem used by the platform.
2. 🌐 **Outlook (Web)**:
   - Opens `https://outlook.live.com/mail/0/deeplink/compose?subject=${subject}&body=${body}` in a new tab.
   - Provides webmail access for tutors using Microsoft Outlook / Office 365 accounts.
3. 💻 **Default Desktop Mail App (`mailto:`)**:
   - Retained for macOS users (Apple Mail) and Windows users with desktop Outlook configured.
   - **Safe Length Guard**: If the encoded URL exceeds 1,800 characters:
     - Automatically copies the complete, un-truncated report text to the user's clipboard (`navigator.clipboard.writeText`).
     - Shows an informative toast notification: *"Full session report copied to clipboard! Opening mail app..."*
     - Opens the email client with the subject line and a summary body, preventing Windows ShellExecute crashes.
4. 📋 **Copy Formatted Subject & Message**:
   - Copies both the subject line and the formatted session report directly to the clipboard with one click.
   - Provides an instant visual checkmark confirmation.

## 5. OS-Level Configuration Guide (For Windows Users)

If a Windows user wants browser `mailto:` links to open their preferred email tool natively, they can follow these one-time steps:

### Option A: Make Chrome open `mailto:` links in Gmail
1. In Google Chrome, go to [Gmail](https://mail.google.com).
2. Look at the right side of the address bar for the **Service Handler icon** (two overlapping diamond shapes `⧉`).
3. Click the icon and select **Allow** (`mail.google.com to open all email links`).
4. If the icon is not visible:
   - In Chrome, open `chrome://settings/handlers`.
   - Ensure "Sites can ask to handle protocols" is turned ON.
   - Under Email, set `mail.google.com` as the default.

### Option B: Set Default Email Client in Windows Settings
1. Open Windows **Settings** (Win + I).
2. Navigate to **Apps** > **Default apps**.
3. Search for **Email** or scroll to the `MAILTO` protocol.
4. Choose your preferred app (e.g., **Google Chrome**, **Outlook**, or **Thunderbird**).
